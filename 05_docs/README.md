# Docs

- **`01_pipeline_log.md`** — a narrative account of how the preprocessing
  pipeline (`../02_preprocessing/`) was run: raw data transfer, sample-sheet
  construction, reference genome preparation (including two annotation
  quirks that needed manual fixes), running nf-core/rnaseq, building the
  cross-genome gene-ID crosswalk, and GO annotation.
- **`02_student_RNA_walkthrough.md`** — a teaching document walking through the
  conceptual steps of an RNA-seq pipeline (QC, trimming, alignment,
  counting) manually on a single sample, to make explicit what
  nf-core/rnaseq automates. Written by Jean-Charles de Coriolis; author
  attribution retained.
